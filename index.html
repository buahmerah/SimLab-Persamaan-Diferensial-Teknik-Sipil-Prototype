Persamaan Diferensial (PD) Solusi = Kurva Fungsi y(t)

Yang dicari adalah sebuah Fungsi y(t)

PD menyatakan hubungan antara fungsi dan laju perubahannya: dy/dt = r · y. Solusinya adalah seluruh kurva fungsi y(t) = C·e^(rt) yang menggambarkan perilaku sistem sepanjang waktu!

Intuisi Ujian: Solusi umum memiliki konstanta C (keluarga fungsi). Nilai awal y(t₀) = y₀ memilih satu kurva unik dari keluarga fungsi tersebut.

Eksplorasi Medan Arah (Slope Field)

Setiap panah kecil menunjukkan kemiringan dy/dt di titik (t, y). Fungsi solusi y(t) adalah kurva yang "mengalir" mengikuti panah-panah ini.

Bank Soal Latihan UAS Teknik Sipil

Pelajari langkah-langkah analitik menemukan fungsi solusi dari persamaan diferensial.

Soal 1: PD Orde-1 Linear (Pengurasan Tangki / Faktor Integrasi) ▼

Tentukan fungsi tinggi muka air h(t) yang memenuhi: dh/dt + 0.2h = 4 dengan syarat awal h(0) = 5 meter.

Langkah Penyelesaian:
1. Faktor Integrasi: μ(t) = e^(∫0.2 dt) = e^(0.2t)
2. Kalikan PD dengan μ(t): d/dt [ h(t)·e^(0.2t) ] = 4·e^(0.2t)
3. Integralkan kedua ruas: h(t)·e^(0.2t) = 20·e^(0.2t) + C
4. Solusi Umum (Keluarga Fungsi): h(t) = 20 + C·e^(-0.2t)
5. Substitusi h(0) = 5 → 5 = 20 + C → C = -15
Jadi Fungsi Solusi: h(t) = 20 - 15·e^(-0.2t)
Soal 2: PD Orde-2 Homogen (Getaran Bebas Teredam) ▼

Selesaikan persamaan getaran bebas kolom gedung: y'' + 4y' + 13y = 0 dengan y(0) = 2 dan y'(0) = -1.

Langkah Penyelesaian:
1. Persamaan Karakteristik: r² + 4r + 13 = 0
2. Akar kompleks: r = (-4 ± √(16 - 52)) / 2 = -2 ± 3i
3. Bentuk fungsi osilasi teredam: y(t) = e^(-2t)(C₁·cos(3t) + C₂·sin(3t))
4. Dari y(0) = 2 → C₁ = 2
5. Turunkan y'(t): y'(0) = -2C₁ + 3C₂ = -1 → -4 + 3C₂ = -1 → C₂ = 1
Jadi Fungsi Solusi: y(t) = e^(-2t)(2·cos(3t) + sin(3t))
Soal 3: PD Orde-2 Tak Homogen (Koefisien Tak Tentu) ▼

Cari solusi umum fungsi y(t) dari: y'' - 3y' + 2y = 4e^(3t).

Langkah Penyelesaian:
1. Homogen: r² - 3r + 2 = 0 → (r - 1)(r - 2) = 0 → r₁=1, r₂=2
y_h(t) = C₁·e^t + C₂·e^(2t)
2. Tebakan Partikular: y_p(t) = A·e^(3t)
3. Substitusi ke PD: 9A·e^(3t) - 9A·e^(3t) + 2A·e^(3t) = 4e^(3t)
2A = 4 → A = 2 → y_p(t) = 2e^(3t)
Solusi Umum: y(t) = C₁·e^t + C₂·e^(2t) + 2e^(3t)

Ringkasan Metode Penyelesaian PD (Persiapan UAS)

1. PD Orde-1 Terpisah (Separable)
dy/dx = g(x)·h(y) ⇒ ∫ (1/h(y)) dy = ∫ g(x) dx + C
2. PD Orde-1 Linear (Faktor Integrasi)
dy/dx + P(x)y = Q(x) ⇒ μ(x) = e^(∫P(x)dx)
y(x) = (1/μ(x)) [ ∫ μ(x)Q(x) dx + C ]
3. PD Orde-2 Koefisien Konstan: ay'' + by' + cy = 0
  • • Akar Riil Berbeda (r₁ ≠ r₂): y(t) = C₁·e^(r₁t) + C₂·e^(r₂t)
  • • Akar Riil Kembar (r₁ = r₂ = r): y(t) = (C₁ + C₂·t)·e^(rt)
  • • Akar Kompleks (α ± βi): y(t) = e^(αt) [ C₁·cos(βt) + C₂·sin(βt) ]
4. Aplikasi Teknik Sipil
  • • Getaran Jembatan: m·y'' + c·y' + k·y = F(t) (Syarat Awal: y(0), y'(0))
  • • Lendutan Balok: EI·y'''' = -q(x) (Syarat Batas di x=0 dan x=L)
  • • Hidrasi / Reaksi Kimia: dC/dt = -k·C (Peluruhan eksponensial)
